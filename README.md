This project presents the implementation and evaluation of multiple deepfake detection approaches designed to distinguish authentic videos from AI-generated media. Using the Celeb-DF (v2) dataset, we first developed a baseline convolutional neural network (CNN) model and then expanded our approach by exploring transfer learning with several established CNN architectures. In addition, we designed a custom feature-based model that targeted characteristics commonly associated with weaknesses in deepfake generation. We evaluated each approach using standard performance metrics including accuracy and AUC. Our best-performing model achieved 79.0% accuracy and a 0.764 AUC score, exceeding initial expectations and demonstrating the effectiveness of combining deep learning techniques with domain-specific feature analysis. This work contributes to ongoing efforts to improve the reliability of automated deepfake detection systems and preserve trust in digital media as AI-generated content becomes increasingly sophisticated.
